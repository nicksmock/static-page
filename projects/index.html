Auditing the lab before documenting it

The lab runs my media and book libraries (Jellyfin, Komga, Calibre-Web) and filtered DNS for the house: about 20 containers on one Unraid server, a Raspberry Pi, and a backup host. In October 2026 I audited its four systems, the Unraid server, the UniFi network, the DNS resolver, and the Cloudflare zone and tunnel, one at a time. Collection was read-only, with a written list of forbidden commands per system and read-only API credentials where the system offered them. Nothing was recorded as fact until it was observed on the live system. Every finding carries a severity and a status of open, fixed, or accepted, is never deleted, and is not marked fixed on my word: the data is re-collected and the earlier output kept next to the new. The output is current-state docs for each system and nine runbooks covering disk, flash, restore, DNS, network, and Cloudflare tasks.

kronos, the backup host

A Lenovo ThinkCentre running Debian 13 with a ZFS mirror of two SSDs. The first build used reused hard drives that threw I/O errors; I replaced them with the SSDs. Every night it pulls the Unraid server's container backups and a copy of its flash drive over SSH, keeps 14 daily, 8 weekly, and 6 monthly snapshots with sanoid, then sends an encrypted, deduplicated copy to Backblaze B2 with restic. Only kronos holds a key; the server it backs up has no credential for it, so taking over the server does not reach the backups. Three copies on three kinds of storage: the Unraid array, the ZFS mirror, and object storage. Job failures, ZFS events, and SMART problems alert to Discord. Only SSH listens, keys only, no root login.

Home lab · Debian 13, ZFS, sanoid, restic, Backblaze B2

Network and DNS

A UniFi gateway, PoE switch, and three access points with five VLANs (management, trusted, services, IoT, guest) under a zone-based firewall. No port forwards and UPnP off; the only way in is a Cloudflare Tunnel the server opens outbound, with Traefik routing by hostname and CrowdSec behind it. Guest and IoT are isolated from the internal networks, and intrusion prevention runs in block mode on every VLAN. DNS is two AdGuard Home resolvers, a Raspberry Pi as primary and a container replica synced from it every 15 minutes, handed out by DHCP on every network with no public fallback. The primary serves DNS over TLS, QUIC, and HTTPS with a Let's Encrypt certificate that acme.sh renews through a DNS-01 challenge on a Cloudflare token scoped to that one zone. Upstreams are Quad9 and Cloudflare over DoH with DNSSEC on.

The diagram, generated from data

The lab diagram is built from a TOML file by a Python script with no dependencies beyond the standard library. Hosts, containers, networks, data paths, and the daily schedule are data; the script lays them out, embeds the logos, computes the server, container, and network counts, and writes a self-contained SVG. Updating the diagram means editing data, not drawing.
